## Shortcuts

| Action | Keys |
| --- | --- |
| Raise or dismiss the HUD | `` ` `` |
| Move across the grid | Arrow keys |
| Previous or next workspace | Shift + Left, Shift + Right |
| Jump to a pinned service | Hold `` ` ``, press `0` to `9` |
| Open the highlighted service | Enter |
| Dismiss the HUD | Esc |

In the HUD, typing filters services across every workspace.

![Settings, Shortcuts: the fixed list of keyboard shortcuts.](../../../assets/screenshots/settings-shortcuts.png)

## Pinning a service

Set `pin` to a single digit on the service (in its settings or in `config.yaml`). At most ten services can be pinned, one per digit.

## Typing in fields

Shortcuts are ignored while you are typing in a form field, so a literal backtick in a text box works normally.

## Rebinding

Shortcuts are fixed for now; there is no rebinding.
